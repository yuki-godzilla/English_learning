# Yuki × Chappy English Journal

> 話したことを、次に話せる英語へ。

会話を振り返り、表現を思い出し、英語力の成長を確認するための学習記録です。

## ▶ まずここから

[**最新セッションを振り返る**](learning-records/journal.md#journal-sessions)

Journalの目次とセッション一覧は新しい順です。最新回はそこから開けます。

<details>
<summary><strong>プロジェクト構成・保守情報</strong></summary>

学習記録の正本は次の3ファイルです。

- [English Journal](learning-records/journal.md): セッション、復習、成長の説明、3つの学習バンク
- `learning-records/progress.json`: 評価履歴と資格スコア目安
- `learning-records/media-manifest.json`: 画像の用途、出典、ライセンス、プライバシー確認

Learning Siteはこの3入力から自動生成します。生成物と固定アーカイブは通常の編集元にしません。

後追い評価に利用できる元発話は、公開前に機密箇所を伏せた[raw transcriptの台帳](learning-records/transcripts/coverage.json)で収録範囲を確認できます。欠落回をJournalの要約から再構成しません。raw transcriptはSiteやPDFへ自動掲載しません。
